# Ограничения: чем пришлось пожертвовать

Morrowind (2002) проще Oblivion (2006): у него нет части механик, а у формата — свои пределы. Здесь
собрано всё, что при переносе теряется или упрощается. Подробности — на страницах
[типов записей](types/index.md).

Ограничения делятся на четыре вида:

- **Нет в Morrowind**: механики нет в движке. Обойти можно разве что плагинами вроде MWSE, а цель
  проекта — оригинальный движок без дополнений.
- **Предел формата**: механика есть, но поле или лимит уже. Переносится приближённо.
- **Решение автора**: можно было бы сделать иначе, выбран более простой или более безопасный путь.
- **Ещё не сделано**: в планах.

## Мир

| Что | Вид | Как сейчас |
|---|---|---|
| Несколько worldspace | нет в Morrowind | один мир за прогон, со смещением на свободное место сетки |
| Ячейка 4096 → 8192 | предел формата | 2×2 ячейки в одной, плотность ссылок до 4 раз выше |
| Смешивание текстур земли | нет в Morrowind | на патч 512 единиц — одна текстура: та, которой в нём видно больше всего |
| Мелкие пятна текстур земли | решение автора | патч, не совпавший ни с одним соседом по стороне, получает текстуру соседей — иначе земля пятнистая |
| Крутые обрывы | предел формата | шаг высоты ±1 016 — обрыв становится крутым склоном |
| Уровень воды снаружи | нет в Morrowind | вода всегда на нуле |
| Ландшафт городов | решение автора | берётся только ландшафт родительского мира |
| Процедурная трава | нет в Morrowind | `GRAS` — просто `STAT`, по земле не раскидывается |
| Вид погоды (небо, туман, облака) | нет в Morrowind | только тип погоды из 10 и шанс; вид задаёт `Morrowind.ini` |
| Несколько регионов у ячейки | предел формата | один, по приоритету |
| Масштаб объекта вне 0.5…2.0 | предел формата | зажимается; большие деревья выходят меньше (масштабированных копий мешей не делаем — решение владельца, 2026-10-29) |
| Сетки путей между ячейками | нет в Morrowind | связи через границу ячейки теряются |
| Включение по родителю, квестовые выключения | нет в Morrowind | изначально выключенное не ставится |
| Один объект, поставленный дважды в одну точку | решение автора | ставится один: Construction Set такие пары убирает сам |
| Владельцы (кража) | ещё не сделано | нет |
| Точки входа на новые земли | решение автора | отдельный мод или консоль |
| Карта мира | нет в Morrowind | карта одна на игру и до новых земель не достаёт (без патчей — до x = 28, с Morrowind Code Patch — до x = 51); по желанию — рисованная карта мира из Oblivion в окне карты через [дополнение для MWSE](usage.md#lua-map) |
| Изменения мира из модов | ещё не сделано | мир читается из одного плагина |

## Модели

| Что | Вид | Как сейчас |
|---|---|---|
| Частицы | предел формата | постоянные эффекты (огонь, дым, искры) становятся эмиттерами Morrowind, упрощённо: объём — коробка, темп рождения — средний, без ветра и столкновений |
| Частицы по событию (ловушки, открытие врат, вспышки по скрипту) | нет в Morrowind | не переносятся |
| Анимация в меше | ещё не сделано | меш застывает в позе файла |
| Анимация открытия двери | нет в Morrowind | движок сам поворачивает дверь на 90° вокруг начала меша; у двери с одной створкой петля переносится туда |
| Двери с рамой в том же меше, двустворчатые, подъёмные решётки, крышки | ещё не сделано | поворачиваются целиком вокруг начала меша |
| Направление, угол и скорость открытия | нет в Morrowind | всегда 90° по часовой стрелке за секунду; около трети дверей на петле открываются в другую сторону |
| Карты нормалей, параллакс, отражения | нет в Morrowind | только слоты base и glow |
| SpeedTree: ветер, LOD | нет в Morrowind | дерево — статичный меш, построенный один раз |
| Около 70 мешей старых версий | ещё не сделано | не читаются |

## Предметы и магия

| Что | Вид | Как сейчас |
|---|---|---|
| Эффекты без аналога (скриптовые, отражение урона, поднятие трупа, призыв отсутствующих существ) | нет в Morrowind | выбрасываются; вещь или заклинание без эффектов не пишется |
| Новые магические эффекты | нет в Morrowind | только существующие 137, по таблице |
| Больше 8 эффектов | предел формата | обрезка |
| Малая сила | нет в Morrowind | заклинание за 0, «всегда удаётся» |
| Яд (`SPEL`) | нет в Morrowind | не переносится |
| Сигильские камни | нет в Morrowind | простой предмет без эффектов |
| Чёрные и заполненные камни душ | нет в Morrowind | становятся пустыми ванильными |
| Число в строке уровневого списка | предел формата | 1; золото — монетами-номиналами |
| «Брать все» во вложенном списке | нет в Morrowind | обычный выбор |
| Цены | решение автора | как в Oblivion (дорогие вещи в 10–20 раз дешевле ванильных); по желанию — подтяжка |
| Звуки контейнеров | нет в Morrowind | нет |
| Мебель (сесть, лечь) | нет в Morrowind | обычный активатор |
| Кожа расы под бронёй на её слоте | нет в Morrowind | остаётся имперской |
| Больше 7 частей брони | предел формата | лишние пустые слоты отбрасываются |

## Актёры

| Что | Вид | Как сейчас |
|---|---|---|
| Морфинг лиц | нет в Morrowind | лицо запекается: своя голова и текстура на каждое лицо |
| Тело особых рас | решение автора | тело ванильной расы-донора |
| Характеристики NPC | решение автора | автоподсчёт Morrowind; числа Oblivion — отложенный вариант |
| Уровень «от игрока» | нет в Morrowind | постоянный, середина диапазона |
| Расписания ИИ | нет в Morrowind | wander на месте или стоять |
| Несколько фракций NPC | нет в Morrowind | одна; вторые — метки для диалогов |
| Знаки рождения NPC | нет в Morrowind | нет |
| Модели и анимации существ на донорах | компромисс | 239 из 914 — на моделях ванильных существ Morrowind того же вида |
| Анимация существ со своей моделью | предел формата | одна лента на папку модели: простой, ходьба, бег, повороты, три удара, реакция на удар, заклинание; блок, прыжок, плавание, стойки с оружием и свои простои записей — нет |
| Смерть существ | нет в Oblivion | клипа смерти нет (рэгдолл): тело опрокидывается набок, одинаково у всех |
| Звуки существ со своей моделью | компромисс | `SNDG` — шаги, заметил, атака, удар по существу; простой, смерть, оружие, плавание и `Sound:` из клипов — нет; в игре не проверено |
| Движение лица и частицы на существах | предел формата | нет |
| Существа без донора и без частей тела (11 из 914) | нечем показать | не переносятся; строка списка отпадает, пустой список не пишется |
| Число существ в строке списка | предел формата | 1 |
| Существо-шаблон и скрипт списка существ | нет в Morrowind | нет |
| Синхронизация губ | нет в Morrowind | рот движется по громкости |

## Диалоги и скрипты

| Что | Вид | Как сейчас |
|---|---|---|
| Скрипты | ещё не сделано | не переносятся; нужен свой компилятор MWScript |
| Квесты: стадии, журнал | решение автора | не переносятся |
| Реплики квестов, которые стартуют не с игрой | решение автора | не переносятся |
| Разговоры NPC между собой | решение автора | не переносятся (кроме оклика `HELLO`) |
| Условия без аналога | нет в Morrowind | реплика отбрасывается целиком |
| Больше 6 условий, больше 8 копий | предел формата | реплика отбрасывается |
| Скрипт-результат реплики | ещё не сделано | отбрасывается |
| Несколько ответов в реплике | предел формата | склеиваются в один текст и один файл голоса |
| Текст длиннее 512 | предел формата | продолжение через выбор «Continue» |
| Эмоции ответов | нет в Morrowind | нет |
| Мини-игра убеждения | нет в Morrowind | реакции → ванильные темы Admire/Intimidate; хвастовство и шутки не переносятся |

## Что не переносится вовсе

`GMST`, `BSGN`, `SKIL`, `EFSH`, `CSTY`, `IDLE`, `ANIO`, `WATR`, `ROAD`, `SBSP`, `LSCR` — см.
[Что не переносится](types/not-converted.md).
