# Текстуры и иконки

**Код:** `mesh_convert::textures`, `mesh_convert::icons`, `mesh_convert::face_texture`

## Текстуры

Oblivion и Morrowind оба читают **DDS**, поэтому текстуры **копируются, а не конвертируются**.

| Oblivion | Morrowind | Правило |
|---|---|---|
| `textures\architecture\anvil\anvilwall01.dds` | `Textures\ob_architecture_anvil_anvilwall01.dds` | путь относительно `textures\`, `\` → `_`, префикс `ob_` |
| слот base | base | копия |
| слот glow | glow | копия |
| карта нормалей `*_n.dds`, parallax, отражения | — | у Morrowind таких слотов нет |
| текстура земли `LTEX` | `Textures\ob\<имя>_<хеш>.dds` | см. [Ландшафт](../types/land.md) |
| картинки книг | `BookArt\ob_<имя>_<хеш>.dds` | см. [Книги](../types/book.md) |

Два разных источника, давших одно имя, обрывают прогон с именами обоих (на `Oblivion.esm` таких 0).

**Кожа лиц** — исключение: её конвертер создаёт сам. На каждое лицо — своя текстура `obface_…`
(DDS DXT1 с мипмапами, свой кодировщик): текстура расы, умноженная на карту детализации лица. См.
[Лица](../types/faces.md).

## Иконки

Иконки Oblivion — 64×64, ванильные Morrowind — 32×32, и движок рисует иконку в собственном размере:
иконки Oblivion в инвентаре были вдвое крупнее. Поэтому иконка **уменьшается до 32×32** и кладётся в
`Icons\ob\<имя>_<хеш>.dds`.

## Что теряется

- Карты нормалей, параллакс, отражения (`*_n.dds`, `*_g.dds`, environment): освещение плоское.
- Возрастные текстуры рас.

!!! warning "Не проверено в игре"
    Длинные имена текстур в NIF (до 74 знаков; у ванили имена короткие).
