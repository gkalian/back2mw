# Меши (NIF)

**Код:** `mesh_convert` · подробности формата — [NIF Oblivion](../formats/nif-oblivion.md)

## В Oblivion

NIF версии **20.0.0.4** (основная; 20.0.0.5 — около 1 %, ещё встречаются 10.x). Геометрия — полосы
`NiTriStrips`, коллизия — Havok (`bhk*`) в своих единицах (игровые / 7), анимация —
`NiControllerManager` с последовательностями, частицы — `NiPSys*`, скиннинг с разбиением на
партиции. В архивах Oblivion — около 8 000 мешей, 112 типов блоков.

## В Morrowind

NIF **4.0.0.2**. Геометрия — `NiTriShape` (списки треугольников), коллизия — `RootCollisionNode` с
обычными треугольниками, частицы — старые эмиттеры (`NiParticleSystemController`), анимация — свои
контроллеры, один набор UV на форму.

## Как переносит back2mw

Конвертер **пишет NIF сам**, без внешних программ (через библиотеку `Greatness7/tes3`).

| Oblivion | Morrowind | Правило |
|---|---|---|
| `NiTriStrips` | `NiTriShape` | полосы → треугольники с сохранением обхода; вырожденные склейки выбрасываются |
| иерархия `NiNode` | та же | имя, флаги, сдвиг, поворот, масштаб; перед именем на `Collision` ставится `ob_` — меш с таким именем корня роняет Construction Set |
| вершины, нормали, цвета, UV | те же | один набор UV — тот, что просит base-текстура |
| `NiMaterialProperty` | то же | цвета, блеск, прозрачность; ambient 0 → diffuse (иначе в тени чёрное) |
| `NiAlphaProperty`, `NiVertexColorProperty` | те же | биты, которых нет у 4.0.0.2, снимаются |
| `NiTexturingProperty` | слоты base и glow | см. [Текстуры](textures.md) |
| коллизия `bhk*` (полосы, выпуклые тела, коробки, сферы, капсулы…) | `RootCollisionNode` | треугольники, координаты × 7 |
| `NiBillboardNode`, свет в меше | поддерживаются | |
| скиннинг на мировых объектах | **запекается в позу файла** | 40 мешей |
| скиннинг брони и одежды | пересаживается на скелет Morrowind | см. [Броня и одежда](../types/armo-clot.md) |
| анимация, связи Havok | читаются и выбрасываются | меш в позе файла |
| частицы `NiPSys*` | эмиттеры Morrowind (`NiParticleSystemController`) | постоянные эффекты — огонь, дым, искры; из 553 систем переносятся 300 |
| формы больше 65 535 вершин | делятся | |

Итог: конвертируются 7 966 из 8 035 мешей моделей; полный прогон `Oblivion.esm` — 8 571 меш,
`niftest` чист.

## Что теряется

- **Частицы по событию**: облако газа ловушки, вспышка открывающихся врат, пыль от обвала — у
  Morrowind такой эмиттер нечем запустить, поэтому они не переносятся (237 систем из 553). Постоянные
  эффекты переносятся, но проще: цилиндр и сфера эмиттера становятся коробкой, частицы с поверхности
  меша рождаются в коробке вокруг него, темп рождения — средний, ветра, сопротивления и столкновений
  частиц нет.
- **Анимация в меше**: двери, рычаги, механизмы, флаги на ветру застывают. Исключение — существа:
  их анимация переносится ([существа](../types/crea.md)).
- Слои текстур, кроме base и glow.
- Коллизия не у корня меша (около 180 мешей) и свойства Havok: материал, масса, слои.
- Около 70 мешей не читаются: старые 10.0.1.x с Havok и маркеры 4.0.0.2.

!!! warning "Не проверено в игре"
    Как меш без `RootCollisionNode` ведёт себя в оригинальном движке; вид материалов.
