# Звуки и голоса

**Код:** `mesh_convert::audio`, `mesh_convert::audio::mp3`

ffmpeg не нужен: форматы обеих игр совпадают.

## Звуки (`.wav`)

| | Oblivion | Morrowind |
|---|---|---|
| Формат | PCM 16 бит; 44 100, 22 050, 32 000, 11 025, 16 000 Гц | PCM 16 бит; чаще 22 050 Гц |
| Каналы | моно и стерео (233 из 2 093) | моно (стерео — 1 файл) |
| Где | `Oblivion - Sounds.bsa` | `Sound\Fx`, `Sound\Cr` — **только с диска** |

**Перенос:** моно копируется байт в байт, стерео сводится в моно средним каналов, частота не
меняется. Файл — `Sound\ob\<имя>_<хеш>.wav`. Звуки всегда ставятся отдельными файлами, даже при сборке
в BSA: оригинальный движок не читает звуки из архивов.

## Голоса (`.mp3`)

| | Oblivion | Morrowind |
|---|---|---|
| Формат | mp3 44 100 Гц моно 64 кбит/с, CBR | то же |
| Путь | `sound\voice\<плагин>\<раса>\<m\|f>\<квест>_<тема>_<FormID>_<N>.mp3` | `Sound\Vo\…`, путь — в `SNAM` реплики |
| На реплику | файл на **каждый ответ** | **один файл** |
| Губы | `.lip` к каждому файлу | рот движется по громкости |

**Перенос:** ответы реплики склеиваются **кадрами mp3** без перекодирования (теги ID3 отрезаются,
формат проверяется в каждом кадре). Папка голоса — по «голосовой расе» (`VNAM` расы: у бретонки —
имперская, у тёмных и лесных эльфов — высоких, у орков — нордская, у каджитов — аргонианская). Общая
реплика размножается по парам раса + пол, у каждой — свой файл. Файл — `Sound\Vo\ob\<хеш>.mp3`.

## Что теряется

- `.lip` — синхронизация губ.
- Сдвиг и случайность частоты, флаги `SOUN` — см. [Звуки](../types/soun.md).
