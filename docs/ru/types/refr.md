# REFR, ACHR, ACRE — размещения и замки

**Статус:** 🟡 частично · **Morrowind:** ссылки в ячейках · **Код:** `transform::exterior`

## В Oblivion

Размещение — отдельная запись: `REFR` (объект), `ACHR` (NPC), `ACRE` (существо). Позиция и углы
(радианы), масштаб `XSCL`, **родитель включения** (`XESP` — ссылка включается и выключается вместе с
другой), телепорт, маркер карты (`XMRK`), замок (`XLOC`), владелец (`XOWN`), семя дерева (`XSED`),
флаг «изначально выключена».

## В Morrowind

Ссылка — часть записи ячейки (`FRMR` + поля): объект, позиция, углы (та же раскладка), масштаб
**0.5…2.0**, назначение двери, замок (`FLTV`) и ключ (`KNAM`), ловушка, владелец. Ссылки делятся на
постоянные и временные; ссылки на NPC и существ у ванили **всегда постоянные**, на списки существ —
всегда временные.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| `REFR` | ссылка | только на перенесённые объекты |
| позиция, углы | как есть (+ смещение снаружи) | |
| масштаб | зажат в 0.5…2.0 | |
| выключенные (сами или через родителя) | — | не ставятся |
| маркеры (`XMRK`, модели `marker*`, `*lod.nif`) | — | не ставятся |
| вторая такая же ссылка в ячейке (тот же объект, точка и поворот) | — | не ставится: Construction Set убирает такие сам и пишет «Duplicate … removed» |
| `REFR` на звук | невидимый активатор со скриптом | см. [Звуки](soun.md) |
| `ACHR` | постоянная ссылка на NPC | временная роняет игру при разговоре |
| `ACRE` | постоянная ссылка на существо | только на перенесённые существа, см. [Существа](crea.md) |
| `REFR` на список существ | временная ссылка на `LEVC` | как у ванили; существо создаёт движок |
| номер ссылки | по порядку `FormID` | уникален на плагин |

### Замки {#locks}

| Oblivion | Morrowind | Правило |
|---|---|---|
| уровень 0…100 | `FLTV` | 0 → 1 (у Morrowind 0 без ключа — открыто); 100 — остаётся 100 (самый сложный ванильный) |
| «растущий» (сложность от уровня игрока) | `FLTV` + 30 | зажато в 1…100 |
| ключ `KEYM` | `KNAM` | ключ конвертируется, даже если сам в мире не лежит |

У `SEWorld`: заперто 178 ссылок, с ключом 72.

## Что теряется

- **Масштаб вне 0.5…2.0** зажимается (у `SEWorld` с деревьями — 2 950 ссылок). Варианты меша с
  масштабом в корне — в планах.
- **Включение по родителю** (`XESP`): ссылки, выключенные изначально, не ставятся вовсе; квестовые
  включения не работают.
- **Владельцы** (`XOWN`): взять вещь — не кража.
- «Растущие» замки — фиксированный уровень.
- Существа без модели-донора и опустевшие списки существ не ставятся (см. [Существа](crea.md)).
- **Повторные ссылки**: если автор поставил один объект дважды в одну точку с одним поворотом
  (разница меньше юнита по каждой оси и меньше 0.01 рад по каждому углу, масштаб тот же), ставится
  одна. У `SEWorld` таких 84 — камни, грибы, потолки руин, одна тарелка и одна точка появления
  существ.

!!! warning "Не проверено в игре"
    Соглашение о повороте (порядок и знак осей); замки и ключи; убирает ли повторные ссылки сам
    движок игры (Construction Set убирает).
