# GRAS — трава

**Статус:** 🟡 частично · **Morrowind:** `STAT` · **Код:** `transform::world`

## В Oblivion

Запись `GRAS` описывает пучок травы и параметры, по которым движок сам раскидывает его по
ландшафту: плотность, наклон, высоты, текстуры земли, на которых она растёт (`DATA`, 32 байта). В
`Oblivion.esm` — 108 записей. Ссылок на траву в мире нет: её «сажает» движок.

## В Morrowind

Процедурной травы нет. Трава у ванили и модов — обычные `STAT`, расставленные вручную (или MGE XE
со своими средствами).

## Как переносит back2mw

`GRAS` → `STAT` с тем же мешем: запись и модель доступны для расстановки вручную.

## Что теряется

- **Раскидывание по ландшафту.** Перенесённые земли в Morrowind будут без травы, если её не
  расставить отдельно.
- Колыхание ветром.
