# ENCH, SPEL — зачарования и заклинания

**Статус:** ✅ переносится · **Morrowind:** `ENCH`, `SPEL` · **Код:** `transform::magic`

## В Oblivion

**`ENCH`** — тип (свиток, посох, оружие, одежда/броня), заряд, стоимость, флаг «стоимость вручную»,
до 12 эффектов. Заряд в самой записи у посохов и свитков просто равен стоимости; **настоящий заряд
хранит вещь** (`ANAM` оружия или стрелы).

**`SPEL`** — тип (заклинание, способность, малая сила, сила, болезнь, яд), стоимость, уровень
мастерства (0…4), флаги (в том числе «стартовое у игрока»).

В `Oblivion.esm`: `ENCH` 1 542, `SPEL` 1 137.

## В Morrowind

**`ENCH`** — тип (однократно, при ударе, при использовании, постоянно), стоимость, заряд, флаг
автоподсчёта, до 8 эффектов. Заряд хранится в самом зачаровании.

**`SPEL`** — заклинание, способность, болезнь, моровая болезнь, проклятие, сила; стоимость, флаги
«автоподсчёт», «стартовое у игрока», «всегда удаётся», до 8 эффектов. Малой силы нет.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| `ENCH` свиток | однократно | заряд из `ENCH` |
| `ENCH` посох | при использовании | заряд — `ANAM` вещи |
| `ENCH` оружие | при ударе | заряд — `ANAM` вещи |
| `ENCH` одежда и броня | постоянно | |
| одно `ENCH` на вещах с разным зарядом | вариант на каждый заряд | `obc1_…`; первый по возрастанию получает ID записи |
| эффекты | по [таблице эффектов](mgef.md) | больше 8 — обрезка с замечанием |
| `SPEL` заклинание / сила / болезнь / способность | те же типы | стоимость как есть, **без автоподсчёта** |
| малая сила | заклинание со стоимостью 0, «всегда удаётся» | ближе всего по поведению |

Пишутся только зачарования, на которые ссылается вещь того же плагина. Флаг автоподсчёта у `SPEL` не
ставится: у Morrowind он значит ещё и «раздать подходящим NPC».

Итог на `Oblivion.esm`: `ENCH` 1 469 (51 вариант по заряду), зачаровано 2 338 вещей; `SPEL` 1 040 из
1 137.

## Что теряется

- `SPEL` типа «яд» не переносится — аналога у Morrowind нет (в `Oblivion.esm` таких записей нет,
  в модах могут быть).
- Зачарование и заклинание без единого переносимого эффекта не пишется (`ENCH` 21, `SPEL` 97 — почти
  все со скриптовыми эффектами); вещь остаётся без зачарования.
- Уровень мастерства заклинания.
- Флаг «стартовое у игрока»: игроку Morrowind заклинания Oblivion не выдаются.
- Перезарядка малой силы раз в сутки: в Morrowind это обычное заклинание за 0.
- Вещь мода со ссылкой на зачарование мастера остаётся без зачарования.

!!! warning "Не проверено в игре"
    Баланс стоимостей и величин; срабатывают ли постоянные эффекты и «при ударе»; малая сила как
    заклинание со стоимостью 0.
