# TREE — деревья

**Статус:** ✅ переносится · **Morrowind:** `STAT` (по варианту на семя) · **Код:**
`mesh_convert::speedtree`, `transform::objects`

## В Oblivion

Дерево — не меш, а описание **SpeedTree** (`.spt`, SpeedTreeRT 4.x): параметры ствола, веток и
листвы. Движок строит геометрию сам во время игры. Запись `TREE` содержит путь к `.spt`, текстуру
листвы (`ICON`) и список **семян** (`SNAM`): одно и то же описание с разным семенем даёт разные
деревья. Ссылка в мире выбирает семя полем `XSED`, а без него — случайно при каждой загрузке.

В `Oblivion.esm` — 142 записи `TREE` на 139 файлов `.spt`; у 57 записей 4–7 семян. Ссылок на деревья —
141 612.

## В Morrowind

SpeedTree нет. Дерево — обычный `STAT` с готовым мешем.

## Как переносит back2mw

Конвертер **строит меш дерева сам**: собственный генератор SpeedTree, сверенный с движком Oblivion
дизассемблером — тот же генератор случайных чисел, те же сплайны, то же число вершин и листьев.

| Oblivion | Morrowind | Правило |
|---|---|---|
| `TREE` с N семенами | N записей `STAT` | первый вариант — ID записи, следующие — `obt1_…`, `obt2_…` |
| `.spt` + семя | NIF | кора — треугольники из полос веток; листва — карточки с альфа-тестом, обе стороны отдельными треугольниками |
| текстуры | копии | кора из `textures\trees\branches\`, листва — `ICON` записи |
| коллизия | `RootCollisionNode` | только ствол |
| ссылка с `XSED` | ссылка на вариант `XSED mod N` | как движок |
| ссылка без `XSED` | вариант `FormID mod N` | у движка случайно; у нас — постоянно, чтобы сборки совпадали |

Итог на `Oblivion.esm`: 142 записи → 371 вариант, `niftest` чист. В мире `SEWorld` — +8 760 ссылок
на деревья, в `Tamriel` поставлены все.

## Что теряется

- **Колыхание ветром** и смена LOD по расстоянию: меш статический, без LOD. Самые густые деревья —
  около 110 тысяч треугольников.
- Billboard-листва (плоские спрайты, повёрнутые к камере) — карточки неподвижны.
- Коллизия веток и объекты коллизии `.spt` (у 9 деревьев из 139).
- Масштаб больше 2.0 зажимается (у деревьев `Oblivion.esm` — 2 928 ссылок, наибольший 3.33), см.
  [Размещения](refr.md).

!!! warning "Не проверено в игре"
    Двусторонность листвы, производительность густых лесов в оригинальном движке, вид альфа-теста.
