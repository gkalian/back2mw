# CELL — интерьеры

**Статус:** ✅ переносится · **Morrowind:** внутренние `CELL` · **Код:** `transform::interior`

## В Oblivion

Внутренняя ячейка: имя (`FULL`) или только `EDID`, освещение `XCLL` (рассеянный и направленный свет,
цвет и дальность тумана), вода (флаг и `XCLW`), владелец, музыка, регион. Двери-телепорты (`XTEL`)
указывают на дверь на том конце и точку появления игрока. В `Oblivion.esm` — 1 855 интерьеров.

## В Morrowind

Ячейка с **именем-ID** (по нему её находят двери и консоль), `AMBI` — ambient, sunlight, цвет и
**плотность** тумана, вода и её высота, флаг «ведёт себя как внешняя».

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| какие ячейки | — | достижимые дверями из переносимого мира (с городами) и дальше по цепочке дверей |
| `FULL` (нет — `EDID`) | имя-ID | уникально без учёта регистра: повтор получает « 2», « 3»; не длиннее 50 |
| рассеянный, направленный свет, цвет тумана | `AMBI` | как есть |
| дальность тумана `far` | плотность | `1 − far/8192`, зажато в 0…1; туман выключен — 0 |
| вода + `XCLW` | вода + высота | |
| размещения | ссылки | как снаружи, без смещения |
| `XTEL` | `DODT` (+ `DNAM`) | наружу — точка выхода + смещение; в интерьер — как есть, `DNAM` = имя ячейки; иначе без назначения |

Итог для `SEWorld`: 162 интерьера, 41 137 ссылок в них, 439 дверей с назначением; все `DNAM` ведут в
существующие ячейки.

## Что теряется

- Владельцы ячеек, музыка, регион интерьера.
- Интерьеры, недостижимые дверями из мира (тестовые, квестовые, связанные с другими мирами).
- Двери в мир, который не переносится, — без назначения.

!!! warning "Не проверено в игре"
    Формула плотности тумана.
