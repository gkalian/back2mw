# BOOK — книги и свитки

**Статус:** ✅ переносится · **Morrowind:** `BOOK` · **Код:** `transform::items`, `transform::paths::book_art_path`

## В Oblivion

Флаг «свиток», навык-учебник (−1 или один из 21 навыка), цена, вес, текст (`DESC`) в HTML-подобной
разметке со шрифтами `<font face=N>` и картинками `<IMG src="Book/…">` (путь относительно
`Textures\Menus\`). Свиток может нести зачарование. В `Oblivion.esm` — 887 книг, 110 учебников, 181
книга с картинками.

## В Morrowind

Тот же набор: флаг свитка, навык (из 27), цена, вес, текст с разметкой и картинками `<IMG SRC>`
относительно `BookArt\`. Ёмкость зачарования, зачарование свитка.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| флаг свитка, цена, вес | как есть | |
| навык | навык по таблице 21 → 27 | Клинок → длинный клинок, Дробящее → дробящее оружие (`data/skills.tsv`) |
| `<font face=N>` | `"Magic Cards"`, face 4 → `"Daedric"` | шрифты Morrowind |
| `<IMG src>` | `<IMG SRC="ob_<имя>_<хеш>.dds">` | файл копируется в `BookArt\` как есть, ширина и высота тега не меняются |
| зачарование свитка | `ENCH` «однократно» | см. [Зачарования](ench-spel.md) |

## Что теряется

- Уменьшенные копии картинок (`Menus80`, `Menus50`) — не нужны.
- Картинка с путём, непредставимым в cp1252, убирается из текста с замечанием.
- Одна картинка (`Book/Vehk_201x325.dds`) отсутствует в архивах самого Oblivion — ссылка в тексте
  остаётся.
- Скрипты книг.

!!! warning "Не проверено в игре"
    Как Morrowind рисует буквицу 128×64 при `width=70 height=61` (обрезает или сжимает); влезают ли
    крупные картинки (карты); как читается текст с заменёнными шрифтами.
