# ALCH, INGR — зелья и ингредиенты

**Статус:** ✅ переносится · **Morrowind:** `ALCH`, `INGR` · **Код:** `transform::items`, `transform::effects`

## В Oblivion

`ALCH` (зелья, еда, напитки) и `INGR` (ингредиенты): вес, цена, флаги «без автоподсчёта» и «еда»,
список эффектов. Эффект — код (`REHE`, `FOAT`…), величина, площадь, длительность, дальность, атрибут
или навык. У зелий обычно 1 эффект, у ингредиентов 4. В `Oblivion.esm` — 252 зелья и 173
ингредиента.

## В Morrowind

`ALCH` — до 8 эффектов с min/max величиной. `INGR` — ровно 4 слота, и хранит **только эффект,
навык и атрибут**: величину и длительность при поедании и варке движок считает сам.

## Как переносит back2mw

Эффекты — по общей таблице, см. [Магические эффекты](mgef.md).

| Oblivion | Morrowind | Правило |
|---|---|---|
| эффект | эффект Morrowind 0…136 | `data/effects.tsv` |
| величина | min = max = величина | |
| длительность, площадь | как есть | |
| дальность у зелья | всегда «на себя» | |
| эффекты ингредиента | до 4 эффектов без чисел | |
| цена, вес | как есть | |

Итог: у зелий перенесено 320 эффектов, у ингредиентов 645; без единого эффекта осталось 8 зелий
(у них был только скрипт) и 5 ингредиентов.

## Что теряется

- Эффекты без аналога: скриптовые (`SEFF`), отражение урона и др. — см. [Магические эффекты](mgef.md).
- Флаг «еда» (у Morrowind его нет).
- Скрипты.

!!! warning "Не проверено в игре"
    Баланс величин и длительностей Oblivion в Morrowind; варятся ли зелья из перенесённых
    ингредиентов.
