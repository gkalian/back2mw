# LIGH — свет

**Статус:** ✅ переносится · **Morrowind:** `LIGH` · **Код:** `transform::world`

## В Oblivion

Время горения (−1 — вечно), радиус (16…7 000), цвет, флаги (динамический, можно носить, мерцание,
пульсация, прожектор…), затухание (`FNAM`), угол конуса, цена, вес, звук. **Большинство источников —
без модели** (1 328 из 1 625 в `Oblivion.esm`): невидимый свет, расставленный по сцене.

## В Morrowind

Те же поля, кроме затухания и прожектора. Радиус у ванили — до 4 096. Свет без модели тоже бывает
(144 из 574 ванильных).

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| время, радиус, цвет, цена, вес | как есть | |
| флаги 0x1…0x8, 0x20…0x100 | те же | смысл совпадает |
| флаг 0x10, прожектор 0x200/0x400 | — | снимаются (0x10 у Morrowind — «огонь») |
| свет без модели | `LIGH` без `MODL` | как у ванили |
| звук `SNAM` | `SNAM` | см. [Звуки](soun.md) |

## Что теряется

- Затухание (`FNAM`), угол конуса и прожекторы.
- Пламя и искры в меше факела (частицы) переносятся упрощённо — см. [Меши](../resources/meshes.md).

!!! warning "Не проверено в игре"
    Флаг «динамический» стоит лишь у 63 огней Oblivion, а у ванили — у 427 из 574. Если без него свет
    Morrowind не освещает персонажей, флаг надо ставить всем. Радиус 7 000 больше ванильного
    максимума.
