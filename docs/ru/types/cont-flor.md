# CONT, FLOR — контейнеры и растения

**Статус:** ✅ переносится · **Morrowind:** `CONT` · **Код:** `transform::world`

## В Oblivion

**`CONT`** — сундуки, бочки, мешки: флаг «пополняется», **собственный вес** ящика, содержимое
(`CNTO`: предмет или уровневый список + число), звуки открытия и закрытия. 873 записи; в
содержимом 9 971 строка, из них 2 718 — уровневые списки.

**`FLOR`** — растения, с которых собирают урожай: модель плюс ингредиент (`PFIG`). 155 записей.

## В Morrowind

`CONT` — флаги («органический», «пополняется», 0x8 — у всех ванильных), **вместимость** (вес, который
влезает), содержимое. Растения ванили — органические контейнеры с одним ингредиентом внутри. Звуков
у контейнера нет.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| `CONT` | `CONT` | вместимость **200** для всех (мода и медиана ванили): вес ящика Oblivion — не вместимость |
| флаг «пополняется» | 0x02 | как есть; 0x8 — всегда |
| содержимое | `NPCO` | `FormID` → ID, когда весь плагин прочитан |
| уровневый список «брать все» | строки списка прямо в контейнере | число × число строки |
| `Gold001` × N | `Gold_001` × N | точно |
| камень душ | ванильный `Misc_SoulGem_*` | |
| `FLOR` | `CONT`, флаги 0xB | органический, пополняется, вместимость 0, внутри 1 × ингредиент |

Предмет, которого нет в плагине (меш не прочитался, запись не перенесена), выбрасывается из
содержимого: ссылка на несуществующий ID — битая запись.

## Что теряется

- **Звуки** открытия и закрытия (у Morrowind поля нет).
- Скрипты.
- С `--worldspace` переносятся только предметы, стоящие в мире или нужные NPC, — содержимое
  контейнеров из уровневых списков беднее, чем в Oblivion.

!!! warning "Не проверено в игре"
    Собираются ли растения и пропадает ли урожай.
