# FACT — фракции

**Статус:** ✅ переносится · **Morrowind:** `FACT` · **Код:** `transform::factions`

## В Oblivion

Имя, флаги (скрытая — 336 из 476), отношения к другим фракциям (−200…100), ранги с мужским и
женским титулом. NPC может состоять в **нескольких фракциях** (у 1 446 NPC `Oblivion.esm`).

## В Morrowind

Имя, атрибуты и навыки фракции, ранги (до 10, с требованиями), отношения −3…3. NPC — **в одной
фракции** с рангом.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| какие фракции | — | только те, где состоит переносимый NPC |
| `FULL` | имя | без имени — `EDID`, фракция скрыта |
| ранги | ранги | мужской титул, иначе женский, иначе имя фракции; без рангов — один ранг |
| отношения ±100 | ±3 | линейно с зажимом |
| несколько фракций NPC | одна | первая видимая с рангом ≥ 0 |

Вторые фракции не пропадают для диалогов: реплики для фракции, которая у NPC не основная, получают
**метку** — локальную переменную `obf_…` в скрипте NPC (см. [Диалоги](dial.md)).

## Что теряется

- **Вторые фракции** как членство: в Morrowind NPC состоит только в одной.
- Требования рангов (атрибуты, навыки) — пустые; вступить игроку некуда (квесты не переносятся).
- Отношения точнее, чем ±3.
