# HAIR, EYES, FaceGen — лица, причёски, глаза

**Статус:** ✅ переносится · **Morrowind:** своя голова и причёска `BODY` на каждое лицо · **Код:**
`mesh_convert::facegen`, `mesh_convert::head`, `mesh_convert::face_texture`, `back2mw::faces`

## В Oblivion

Лицо **вычисляется во время игры** библиотекой FaceGen. NPC хранит коэффициенты: `FGGS` (симметричная
геометрия, 50), `FGGA` (асимметричная, 30), `FGTS` (текстура, 50). Раса даёт части головы (голова, уши,
рот, зубы, язык, глаза) с базисами морфинга `.egm` (геометрия) и `.egt` (текстура), мимика — `.tri`.
`HAIR` — меш причёски с текстурой из `ICON`, цвет волос — `HCLR` NPC. `EYES` — текстура глаз.

## В Morrowind

**Морфинга нет.** Голова — статический NIF, указанный в `BODY` с частью `Head`; причёска — `BODY` с
частью `Hair`. NPC ссылается на голову и причёску прямо по ID, у каждого может быть своя. Мимика —
морфы `Talk` и `Blink` внутри NIF головы.

## Как переносит back2mw

Лицо **запекается**: на каждое лицо — свой меш головы и своя текстура.

| Oblivion | Morrowind | Правило |
|---|---|---|
| части головы расы + `.egm` × `FGGS`/`FGGA` (NPC + раса) | один NIF головы | коэффициенты NPC — отклонение от лица расы, они складываются; все части сливаются в узле `Head`, оси как у ванили; нормали сварены |
| `.tri` | морфы `Talk`/`Blink` | «говорит» — `BigAah`, «моргает» — `BlinkLeft`/`BlinkRight`; у головы, рта, зубов, языка |
| `.egt` × `FGTS` (NPC + раса) | своя текстура лица DDS DXT1 | карта = 128 + ½·Σ коэффициент·морф; лицо = текстура расы × карта / 128 |
| текстуры частей | из `ICON` расы | как берёт сам Oblivion |
| `EYES` | текстура глаз | |
| `HAIR` | `BODY` причёски | меш с морфом того же лица, текстура `ICON`, цвет `HCLR` — цветом материала |
| ambient материала головы | = diffuse | иначе лицо в тени темнее шеи |

Одинаковые лица делят один меш. Запечённая карта сверена с готовыми картами Oblivion у 1 971 NPC
(корреляция 0.961). Итог для `SEWorld`: 372 головы, 362 причёски, 628 текстур кожи (около 25 МБ).

## Что теряется

- Возрастные текстуры рас.
- `.lip` — синхронизация губ (Morrowind двигает рот по громкости).
- Анимация лица, кроме разговора и моргания (эмоции).

!!! warning "Не проверено в игре"
    Голова Oblivion шире ванильной на 17 % — как она сидит на теле Morrowind; вид кожи и глаз.
