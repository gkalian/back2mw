# APPA — алхимические аппараты

**Статус:** ✅ переносится · **Morrowind:** `APPA` · **Код:** `transform::items`

## В Oblivion

Тип (ступка, перегонный куб, кальцинатор, реторта), цена, вес, качество в процентах (10…100). В
`Oblivion.esm` — 23 записи.

## В Morrowind

Те же четыре типа в том же порядке, качество — дробное число (у ванили 0.5…2.0).

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| тип | тип | как есть |
| качество | качество / 50 | 10…100 % → 0.2…2.0 |
| цена, вес | как есть | |

## Что теряется

Ничего существенного. Скрипты не переносятся.
