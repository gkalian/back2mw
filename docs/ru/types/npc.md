# NPC_, PACK, LVSP — NPC

**Статус:** ✅ переносится · **Morrowind:** `NPC_` с автоподсчётом · **Код:** `transform::npcs` ·
**Флаг:** только с `--worldspace`

## В Oblivion

`NPC_`: раса, класс, пол, уровень (постоянный или **от уровня игрока** со смещением и пределами
calcMin/calcMax), атрибуты, 21 навык, здоровье, магия, усталость, фракции, инвентарь, заклинания
(`SPLO`, в том числе уровневые списки заклинаний `LVSP`), ИИ (агрессия, уверенность, энергия,
ответственность), услуги, лицо FaceGen, причёска и цвет волос, глаза, скрипт. Поведение — **пакеты
ИИ** (`PACK`): расписания «спать, есть, бродить, идти туда-то» по времени суток.

В `Oblivion.esm` — 2 482 NPC, «от уровня игрока» — 1 568.

## В Morrowind

`NPC_`: раса, класс, фракция и ранг, уровень, **либо** все числа вручную, **либо** флаг
автоподсчёта (движок считает атрибуты, навыки и здоровье по классу, расе и уровню), голова и
причёска — ссылки на `BODY`, инвентарь, заклинания, ИИ (драка, бегство, тревога, приветствие),
пакеты ИИ (wander, travel, escort, follow, activate) **без расписаний**. Уровень всегда постоянный.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| характеристики | автоподсчёт | решение автора; вариант «числа Oblivion» описан и отложен |
| уровень постоянный | как есть | |
| уровень «от игрока» | середина calcMin…calcMax | без calcMax — calcMin + смещение, не ниже 1 |
| раса | ванильная или своя | см. [Расы](race.md) |
| класс | класс-вариант по услугам | см. [Классы](clas.md) |
| фракции | одна | см. [Фракции](fact.md) |
| лицо, причёска, глаза | запечённая голова и причёска | см. [Лица](faces.md) |
| инвентарь | `NPCO` | уровневые списки экипировки раскрываются: иначе NPC голые |
| `SPLO` | заклинания | `LVSP` раскрываются по уровню NPC |
| агрессия ≥ 50 | драка 90, иначе 30 | |
| уверенность | бегство `80 − уверенность` | |
| ответственность | тревога | |
| — | приветствие 30 | самое частое у ванили |
| `PACK` | wander на месте | радиус первого пакета-странствия (до 2 000), иначе стоять |
| звериные расы | `base_animkna.nif` | как у ванили |
| `ACHR` | **постоянная** ссылка | с временной NPC не ходит, а разговор роняет игру |
| — | скрипт-метка `ob_npc` | нужен для фильтра диалогов |
| `EDID` | ID не длиннее 23 знаков | предел Morrowind для NPC и существ; слово `NPC` из имени убирается |

С `--worldspace` переносятся NPC, стоящие в мире и его интерьерах, и NPC из строк списков существ,
стоящих там же (см. [Существа](crea.md)). Итог для `SEWorld`: 372 `NPC_` (65 из них — из списков), 285
ссылок, своих рас 3, классов 46, фракций 45.

## Что теряется

- **Числа Oblivion**: атрибуты, навыки, здоровье считает движок Morrowind.
- **Расписания**: NPC не спят, не едят, не ходят по делам — бродят на месте или стоят.
- **Скрипты** NPC.
- Уровень «от игрока» становится постоянным.
- Вторые фракции (только как метка для диалогов).
- Заклинания со скриптовыми эффектами (у `SEWorld` — 54).
- Знаки рождения (`BSGN`) — у Morrowind они только у игрока.

!!! warning "Не проверено в игре"
    Ходят и говорят ли NPC с постоянными ссылками; услуги через класс в оригинальном движке.
