# DIAL, INFO, QUST — диалоги

**Статус:** 🟡 частично · **Morrowind:** `DIAL`/`INFO` · **Код:** `transform::dialogue`,
`tes3_out::dialogue`, `data/conditions.tsv`, `data/voice_topics.tsv` · **Флаг:** только с `--worldspace`

## В Oblivion

`DIAL` — тема одного из типов: Topic (обычная тема), Conversation (разговоры NPC между собой и
оклики), Combat, Persuasion, Detection, Service, Misc. `INFO` — реплика: **несколько ответов** (каждый
со своим файлом голоса и эмоцией), условия `CTDA` (функция, операция, число или глобальная
переменная, флаг «или»), добавить темы, выбор (`TCLT` — переход в другую тему), скрипт-результат.
`QUST` — квест: стадии, журнал, условия на все свои реплики, флаг «старт с игрой». Голос — mp3 в
`Sound\Voice\<плагин>\<раса>\<пол>\` и `.lip` к каждому.

В `Oblivion.esm` — 3 817 тем, 19 278 реплик, 390 квестов.

## В Morrowind

`DIAL` — тема (имя = ID), голос (Voice), приветствие (`Greeting 0…9`), убеждение, журнал. `INFO` —
**один текст** до 512 знаков, один файл звука, поля-фильтры (NPC, раса, класс, фракция и ранг, ячейка,
пол, отношение) и **не больше 6** условий `SCVR`; «или» нет — ваниль делает копии реплики.
Результат — текст MWScript, который движок компилирует сам. Темы голоса и убеждения — ванильные,
движок спрашивает их по имени.

## Как переносит back2mw

**Что отбирается:**

- реплики квестов **со стартом с игрой** и без условий на стадию квеста (`GetStage`, `GetStageDone`,
  `GetQuestVariable`, `GetQuestRunning`);
- реплика, где есть условие без аналога в Morrowind, **отбрасывается целиком**;
- `GetPlayerInSEWorld` вычисляется по переносимому миру, `GetIsPlayableRace` → фильтры «Not Race»;
- «или» → копии `INFO` (не больше 8);
- Conversation не переносится, кроме оклика `HELLO` → голос `Hello`.

**Говорящий вычисляется**, а не переводится по полю: неизменные условия на говорящего (`GetIsID`, раса,
класс, фракция, пол) проверяются по переносимым NPC, и найденный набор пишется полем `ONAM` (один
NPC), общими полями + `Not ID` на лишних, либо копией на каждого NPC (до 8). Фракцию, которая у NPC не
основная, выражает метка `Local obf_… = 0`. Общие реплики получают фильтр `Local ob_npc = 0`: их
говорят только переносимые NPC, а не ванильные.

| Oblivion | Morrowind | Правило |
|---|---|---|
| Topic | тема | имя — `FULL`; тема с именем ванильной — дописывается в её начало |
| `GREETING` | начало `Greeting 0` | переносимые NPC здороваются по-обливионски |
| голосовые темы (Combat, Detection, Service…) | ванильные темы Voice и Persuasion | по таблице ниже; без выбора и прощания |
| ответы реплики | один `NAME` | склеиваются; длиннее 512 — продолжение через `Choice "Continue"` |
| добавить темы | `AddTopic` в результате | |
| выбор `TCLT` | `Choice "<тема>" n` | реплики темы-варианта — копиями с фильтром `Choice = n` |
| скрипт-результат | — | отбрасывается |
| голос ответов | один `.mp3` | кадры склеиваются без перекодирования; `Vo\ob\<хеш>.mp3` |
| общая озвученная реплика | копия на пару раса + пол | у каждой пары свой файл голоса |
| пометка `[… Sound]` у голоса | пустой текст | крик без слов |

Итог для `SEWorld`: 42 темы, 1 116 `INFO`, из них 744 с голосом, 285 файлов голоса.

## Что теряется

- **Квесты**: стадии, журнал, реплики квестов, которые стартуют не с игрой.
- **Разговоры NPC между собой**.
- **Скрипт-результат** реплик (выдача предметов, смена стадий, AI).
- Условия без аналога: `IsGuard`, `GetScriptVariable`, `GetRandomPercent`, нарушение границ и т. п. —
  такая реплика пропадает целиком.
- Реплики, которым нужно больше 6 условий или больше 8 копий.
- Эмоции ответов, `.lip`.
- Убеждение Oblivion `BOAST*` и `JOKE*` (у Morrowind нет аналога).
- Ванильные приветствия (розыск, вампиризм) переносимым NPC не достаются.

!!! warning "Не проверено в игре"
    Играет ли оригинальный движок звук у тем и приветствий (у ванили озвучен только голос) — от этого
    зависит, озвучиваются ли темы; что блок реплик встаёт в начало ванильной темы; фильтры `Not …` с
    `= 1`; что ванильные NPC не проходят фильтр `Local ob_npc = 0`.
