# GLOB — глобальные переменные

**Статус:** ✅ переносится · **Morrowind:** `GLOB` · **Код:** `transform::globals`, `data/globals.tsv`

## В Oblivion

`EDID`, тип (`short`, `long`, `float`), значение (всегда хранится `f32`). Часть переменных ведёт сам
движок: время, дата, масштаб времени. В `Oblivion.esm` — 94 записи.

## В Morrowind

Та же раскладка: имя, тип, значение `f32`. Движковые переменные — свои ванильные (`GameHour`, `Day`,
`Month`, `Year`, `TimeScale`…), 73 в `Morrowind.esm`.

## Как переносит back2mw

| Путь | Правило | `Oblivion.esm` |
|---|---|---|
| ванильная по таблице | движковые переменные: своя копия стояла бы вместо настоящей | 5 |
| ванильная по имени | `EDID` совпал с переменной `Morrowind.esm` без учёта регистра | 1 (`PCVampire`) |
| без пары | строка таблицы с «-» или переменной нет у мастера | 1 (`GameDaysPassed`: `DaysPassed` есть только у Tribunal) |
| своя `ob_…` | всё остальное | 87 |

Тип и значение переносятся как есть; у целых типов дробь отбрасывается, `long` зажимается в ±2^24.
Фильтр `Global` в условиях реплик ведёт туда же, куда сама переменная.
