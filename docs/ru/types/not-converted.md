# Что не переносится

Типы записей Oblivion, которые конвертер не трогает, и почему.

| Тип | Что это в Oblivion | Почему не переносится |
|---|---|---|
| `GMST` | настройки движка | это настройки другого движка; переопределять ванильные `GMST` Morrowind нельзя |
| `BSGN` | знаки рождения | у Morrowind знак рождения — только у игрока, у NPC его нет; свои 13 знаков есть |
| `SKIL` | описания навыков | навыки закрыты движком; переводятся таблицей 21 → 27 (см. [Классы](clas.md#skills)) |
| `EFSH` | шейдеры эффектов (свечение, огонь на теле) | частицы и шейдеры несовместимы |
| `CSTY` | стили боя | аналога нет: у Morrowind ИИ боя один |
| `IDLE` | дополнительные анимации ожидания | аналога нет: анимации — закрытый словарь групп |
| `ANIO` | анимированные объекты | аналога нет |
| `WATR` | типы воды (цвет, отражения, звук) | вода у Morrowind одна, её вид — в `Morrowind.ini` |
| `ROAD` | дороги для ИИ между ячейками | аналога нет |
| `SBSP` | подпространства (блоки, вырезающие воду и т. п.) | аналога нет |
| `LSCR` | экраны загрузки | записи нет; картинки можно положить в `Splash\` вручную |
| `QUST` (стадии, журнал) | квесты | отложено: используются только флаг старта и условия квеста — для отбора реплик |
| `SCPT` | скрипты | см. [Скрипты](scpt.md) |

Частично используется, но своей записи не даёт:

| Тип | Как используется |
|---|---|
| `MGEF` | эффекты ложатся на существующие эффекты Morrowind ([таблица](mgef.md)) |
| `WTHR`, `CLMT` | тип погоды и шансы в регионе ([Регионы](regn.md)) |
| `HAIR`, `EYES` | запекаются в голову NPC ([Лица](faces.md)) |
| `LVSP` | раскрываются в заклинания NPC ([NPC](npc.md)) |
| `PACK` | радиус странствия ([NPC](npc.md)) |
| `SLGM` | ссылки ведут на ванильные камни ([Камни душ](slgm.md)) |
