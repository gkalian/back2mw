# WEAP — оружие

**Статус:** ✅ переносится · **Morrowind:** `WEAP` · **Код:** `transform::weapons`, `transform::prices`

## В Oblivion

Шесть типов: клинок одноручный и двуручный, дробящее одноручное и двуручное, посох, лук. Топоров и
копий как отдельного типа нет: топор — «дробящее», копий в игре нет вовсе. Урон — **одно число**,
есть скорость, дальность (reach), прочность, вес, цена, флаг «игнорирует сопротивляемость
обычному оружию». Модель одна — и в руке, и на земле. Зачарование (`ENAM`) и его **заряд** (`ANAM`)
хранятся в самой вещи.

В `Oblivion.esm` — 1 319 записей, из них зачаровано 942, со скриптом — 130.

## В Morrowind

Десять типов: короткий клинок, длинный клинок 1H и 2H, дробящее 1H и 2H, посох, копьё, топор 1H и
2H, лук (плюс арбалет, метательное, стрелы и болты). Урон — **три пары min–max**: рубящий (chop),
режущий (slash), колющий (thrust). Дальность задаётся типом. Есть ёмкость зачарования.

## Как переносит back2mw

Коэффициенты подобраны по 49 одноимённым парам оружия обеих игр (Iron/Steel/Silver/Dwarven/Glass/
Ebony/Daedric, артефакты) и медианам всех 548 ванильных `WEAP`.

**Тип:**

| Oblivion | Morrowind | Как различаем |
|---|---|---|
| клинок 1H, reach < 1.0 | короткий клинок | Oblivion сам кодирует дальностью: кинжал 0.6, короткий меч 0.8 |
| клинок 1H, reach ≥ 1.0 | длинный клинок 1H | |
| клинок 2H | длинный клинок 2H; копьё | копьё — по слову в `EDID` или имени файла модели: `spear`, `halberd`, `glaive`, `trident`, `lance` |
| дробящее 1H | дробящее 1H; топор 1H | топор — по слову `axe` |
| дробящее 2H | дробящее 2H; топор 2H; копьё | то же |
| посох | посох (дробящее 2H широкое) | |
| лук | лук | |

Правило совпало с ванилью на всех 49 парах.

**Поля:**

| Поле Morrowind | Правило |
|---|---|
| вес | как есть |
| цена | как есть (или подтяжка, см. ниже) |
| прочность | × 5.71, не больше 65 535 |
| скорость | × коэффициент типа (1.14…1.79), у лука 1.0 |
| дальность | медиана ванили по типу: 1.0, у дробящего 2H 1.5, у посоха и копья 1.8 |
| урон | наибольший = урон × коэффициент типа (1.08…2.62); шесть чисел — доли от него, медианы ванили по типу (у топоров и дубин thrust почти 0, у копья главный thrust, у лука только chop) |
| ёмкость зачарования | медиана ванили по типу (35…70) |
| флаг «игнорирует сопротивляемость» | как есть |
| зачарование | своя запись `ENCH`, заряд — из `ANAM` вещи, см. [Зачарования](ench-spel.md) |
| иконка | уменьшается до 32×32, кладётся в `Icons\ob\…` |

Пример: железный длинный меч (урон 10) → chop 2–12, slash 1–17, thrust 3–15; у ванили 2–13, 1–18, 4–16.

### Цены {#prices}

По умолчанию цены — **точно как в Oblivion** (решение автора). Поэтому дорогие вещи у нас в 10–20
раз дешевле ванильных аналогов: стеклянный клеймор 1 150 против 32 000 в Morrowind.

Флаг `--morrowind-prices` (галочка «Подтянуть цены к Morrowind») **поднимает** цену оружия и брони до
кривой Morrowind, если в Oblivion она ниже, и никогда не опускает. Кривая — по ступеням материала:
железо 20 → 40, сталь 45 → 80, серебро 60 → 120, гномье 300 → 600, стекло и эбонит 1 425 → 15 000,
даэдрическое 3 100 → 30 000. На 88 парах типичный промах против ванили — 2.5 раза без подтяжки и
1.25 раза с ней. Стрелы не подтягиваются (у Morrowind они не дороже).

## Что теряется

- **Скрипт** оружия.
- Урон больше 255 и прочность больше 65 535 упираются в предел поля.
- Имя длиннее 31 знака обрезается (в `Oblivion.esm` — одно).
- Вещь без иконки в архивах остаётся без картинки в инвентаре (2 в `Oblivion.esm`).
- Анимации Oblivion (силовые атаки, блок оружием) — у Morrowind свои, общие для типа.

!!! warning "Не проверено в игре"
    Как модель Oblivion сидит в руке: Oblivion крепит оружие к узлу `Weapon`, Morrowind — к
    `Weapon Bone`; ориентация и смещение могут разойтись.
