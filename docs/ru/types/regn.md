# REGN, WTHR, CLMT — регионы и погода

**Статус:** ✅ переносится · **Morrowind:** `REGN` · **Код:** `transform::exterior`, `transform::weather`,
`transform::sounds::region_sounds`

## В Oblivion

**`REGN`** — цвет на карте, имя на карте, приоритет и набор данных: погода (`RDWT`: `WTHR` + шанс),
звуки (`RDSD`), объекты, трава. У ячейки может быть **несколько регионов** (`XCLR`). **`WTHR`** —
полноценная погода: цвета неба по времени суток, туман, облака, освещение, класс (ясно, облачно,
дождь, снег). **`CLMT`** — климат мира: список погод с шансами, солнце и луны.

## В Morrowind

`REGN` — имя, цвет на карте, шансы **10 фиксированных типов погоды** (ясно, облачно, туман, пасмурно,
дождь, гроза, пепельная буря, моровая буря, снег, метель), звуки с шансами, существа для сна. У
ячейки — **один регион**. Как выглядит каждая погода, задаёт `Morrowind.ini`, а не плагин.

## Как переносит back2mw

| Oblivion | Morrowind | Правило |
|---|---|---|
| несколько регионов ячейки | один | с погодой, наибольший приоритет, затем число ячеек, затем меньший `FormID` |
| климат worldspace | `REGN` | для ячеек без региона с погодой |
| `WTHR` | тип погоды | по таблице ниже, иначе по классу |
| шансы погоды | сумма 100 | наибольший остаток |
| имя | имя worldspace | |
| `RCLR` | цвет на карте | |
| звуки `RDSD` | `SNAM` региона | веса к сумме 55, петли — со средним весом; см. [Звуки](soun.md#region-sounds) |

Моровая буря не используется никогда: она заражает игрока.

## Что теряется

- **Вид погоды**: цвета неба, туман, облака Oblivion — у Morrowind они общие в `Morrowind.ini`.
- Солнце и луны климата.
- Флаги погоды и время суток у звуков региона.
- Существа для сна (нет источника), объекты и трава региона.

!!! warning "Не проверено в игре"
    Длинные списки звуков региона (52–56 строк у `SEWorld`, у ванили не больше 27).
