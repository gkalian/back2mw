# SCPT — скрипты

**Статус:** ⛔ не переносятся · **Morrowind:** только служебные скрипты по шаблонам · **Код:**
`tes3_out::Script`

## В Oblivion

Скрипт — текст и скомпилированный байт-код, блоки событий (`Begin GameMode`, `OnActivate`, `OnAdd`,
`OnEquip`, `OnDeath`…), свой набор функций. Скрипты висят на объектах, квестах, эффектах (`SEFF`) и
результатах реплик. В `Oblivion.esm` — 2 393 скрипта.

## В Morrowind

MWScript: **движок исполняет байт-код** (`SCDT`), текст нужен только Construction Set. Скрипт — один
неявный блок, который выполняется каждый кадр, пока объект загружен; события — проверки внутри
(`OnActivate`, `OnPCAdd`…). Набор функций другой.

## Как сейчас

Транслятора скриптов нет. Конвертер пишет **только свои служебные скрипты** по шаблонам, каждый
побайтово сверен с ванильными скриптами того же вида:

| Шаблон | Зачем |
|---|---|
| `LoopSound` | петля звука на активаторе и невидимом маркере звука (как ванильные `Sound_*`) |
| `Locals` | скрипт из одних переменных `short`: метки NPC `ob_npc`, `obf_…` для фильтров диалогов |

Результаты реплик (`AddTopic`, `Choice`, `Goodbye`) — текст MWScript, его компилирует сам движок.

## Что теряется

Вся логика Oblivion на скриптах: рычаги, ловушки, квестовые объекты, поведение NPC, эффекты-скрипты
зачарований и зелий, результаты реплик.

## Планы

Перенос скриптов требует своего компилятора MWScript в байт-код — оракул для него есть: все 632
скрипта `Morrowind.esm` хранят и текст, и байт-код. Объём (все скрипты или только объектные: двери,
рычаги, ловушки) будет решён после переписи команд, которые скрипты Oblivion реально вызывают.
